# Apache Dubbo (apache-dubbo)
Apache Dubbo is a high-performance, Java-based open-source RPC framework that provides service discovery, traffic management, and observability capabilities for building enterprise-level microservices. It supports multiple protocols including Triple (gRPC-compatible), Dubbo, and REST.

## APIs

### Apache Dubbo
Dubbo provides RPC framework APIs in Java and Go for building microservices, with support for multiple protocols (Triple/gRPC, Dubbo, REST), service registry integration, traffic management, and an Admin REST API for service governance.
